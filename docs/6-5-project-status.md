## EntityEvalAgent 设计

### 输出字段

| 字段 | 说明 |
|------|------|
| `doc_id` | 原文 ID |
| `entity` | 金融实体名称（公司/机构/品牌） |
| `mapped_from` | 映射来源，如"文心5.0"→"百度"则填写"文心5.0"，多个用逗号分隔 |
| `entity_sentiment` | 利好/中性/利空 |
| `impact_level` | 大/中/小（中性留空） |
| `sentiment_reason` | 理由 |

### 提取策略

- 只提取金融实体（公司/机构/品牌），不再输出 `financial_relevance` 字段
- 产品/品牌名通过 `mapped_from` 映射到母公司
- 不区分国内外、不区分上市与否

## 已知问题

### 1. 提取遗漏（需修复 eval）

| 文章 | 漏了什么 | 原因 |
|------|---------|------|
| 特斯拉热点汇总 | Fauna Robotics、SpaceX、Meta 等 6 家 | 信息量大的汇总文章，LLM 提取不完整 |
| 三全食品 | 拼多多 | 间接关联实体（投诉发生在拼多多平台） |
| 氪星晚报 | 乐聚机器人、鼎晖百孚等 11 个投资方 | 长尾参与方，LLM 倾向于只提取主实体 |
| 申通快递 | 德殷投资 | 次要股东实体 |

### 2. 多提取/错标（需修复 eval）

| 文章 | 多提了什么 | 原因 |
|------|-----------|------|
| 特斯拉热点 | KEKIUS、狗狗币（加密货币） | 不是公司实体 |
| 四川巴斯特 | 工业硅（大宗商品） | 不是公司实体 |
| 隆坪萤石矿 | 萤石（大宗商品） | 同上 |
| 浪琴表文章 | 蔡文静、张予曦（个人） | 旧版残留问题（新 prompt 已修复） |

### 3. Judge 评测不准（需修复 judge）

| 问题 | 示例 | 影响 |
|------|------|------|
| **LMArena 幻觉** | judge 认为百度、阿里巴巴、智谱AI等是"extra" | 大幅拉低 precision 分数 |
| **来源/媒体误判** | 要求提取新浪网、上证报、同花顺等 | 拉低 recall 分数 |
| **非企业概念** | 要求提取"深圳金融创新大赛"、"斯托克600指数"等 | 同上 |

### 4. 别名问题

| 问题 | 示例 |
|------|------|
| 公司简称 vs 全称 | 我们提"包钢股份"，judge 认为"内蒙古包钢钢联股份有限公司"是遗漏 |
| 子公司 vs 母公司 | "海南三全食品科技有限公司" vs "三全食品" |

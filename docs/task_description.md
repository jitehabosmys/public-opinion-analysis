# 场景名称
金融风控动态舆情分析场景

# 场景概述
当前风险防控环节，外部数据的信息量大，从中筛选具体的风险项通常面临数据量大、人工分析时间长、分析不准确的问题。利用大模型能力结合历史舆情分析情况，精准识别舆情风险，提供分析报告和措施模板。


# 效能预估
本课题预期达成以下效能：
定性层面：对新闻报告或舆情预警信息进行分析，提取结构化报告形成风险措施。
定量层面：保证设计的特征具有较好的业务可解释性和合理性，舆情性质分类准确性至80%以上。


# 数据语料情况
提供不同类别、不同格式的舆情信息和初步分析结果。
